# 江苏臻扬新能源汽车科技有限公司 官网

单页响应式企业官网，深色科技蓝风格。

## 技术栈

- 纯静态 HTML / CSS / JavaScript，零依赖、零构建
- 滚动动效：IntersectionObserver 分段揭示、数字计数、时间轴点亮、首屏轻视差
- 响应式布局：桌面 / 平板 / 手机自适应，移动端自动关闭视差

## 目录结构

```
├── index.html      # 单页主体（10 个板块）
├── css/style.css   # 全部样式
├── js/main.js      # 交互动效
└── images/         # 图片素材（提取自公司宣传册）
```

## 板块

首屏 Hero → 关键数字 → 关于臻扬（双基地布局）→ 发展历程（时间轴）→ 智造基地（产能规划）→ 产品中心（抱箍 / Busbar / 钢扎带 / 钢直条 / 铜铝巴）→ 荣誉资质 → 合作伙伴 → 企业文化 → 联系我们

## 本地预览

```bash
cd website 目录后任选其一：
python -m http.server 8080
# 打开 http://localhost:8080
```
